\section{Architecture Layers}

The system consists of five main layers:

begin{itemize}
    \item {\bold{Client Layer}}: Chats (ChatGPT, DeepSeek, Gemini) and API requests. Flow to Gateway.
}
    \item {\bold{Gateway Layer |\ Monitoram}; Watcher connects to chats and routes commands to Core.
}
    \item {\bold{Core Layer}: Broker server (local API), Orchestrator (fast path) and Agent (OpenAI).
}
    \item {\bold{Adapters Layer}: Controlled connectors to files, databases, browsers, scripts, and systems.
}
    \item {\bold{Persistence Layer}: Logs, audit trail, backups, and operational memory.
}
\end{itemize}
