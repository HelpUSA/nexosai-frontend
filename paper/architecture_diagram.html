Textual Description of Architecture

The system consists of five main layers:

  1. Client Layer: Chats (ChatGPT, DeepSeek, Gemini) and API requests.
  2. Gateway Layer: Watcher connects to chats and routes commands to the Broker and Orchestrator.
  3. Core Layer: Broker server (local API), Orchestrator (fast path) and Agent (OpenAI for reasoning).
  4. Adapter Layer: Controlled connectors to files, databases, browsers, scripts, and systems.
  5. Persistence Layer: Logs, audit trail, backups, and memory storage.
