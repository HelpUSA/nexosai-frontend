# NexosAI Cloud

Cloud command center for NexosAI Cloud Mesh.

Bootstrap admin: helpus.ecommerce@gmail.com via NEXOSAI_BOOTSTRAP_ADMIN_EMAIL.

## MVP surfaces

- Google login
- Dashboard
- Nodes
- Projects
- Conversations
- Downloads
- Admin

## Node types

- Light Node: browser extension relay only
- Full Node: extension plus local AI Bridge execution

## Safety defaults

- Cloud coordinates identity, routing, distribution, backup, observability, and audit.
- Local execution remains local by default.
- No arbitrary remote command execution in the MVP.
